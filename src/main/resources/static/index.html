지갑 등록 (Sessions flow · Apple Pay / Google Pay)

POST /api/sessions → Adyen /sessions 로 세션 생성 → 지갑 승인 → SDK가 /sessions/{id}/payments 를 직접 호출. amount 0 = 0원 인증, >0 = 결제+저장. storePaymentMethod=true · shopperInteraction=Ecommerce. 상단 shopperReference 필수. 완료 후 GET /storedPaymentMethods 를 자동 조회해 새 결제수단을 🆕 로 강조한다.

세션 금액·통화는 생성 시 고정이다. 바꾸면 "세션 생성 후 지갑 마운트"를 다시 눌러야 한다. Apple Pay는 Safari + HTTPS + Adyen 도메인 등록이 필요하고, Google Pay는 Chrome에서 localhost로도 동작한다(TEST).
